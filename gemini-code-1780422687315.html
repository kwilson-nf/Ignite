VPN & Remote Access

All remote employees must connect to the corporate VPN to access internal tools and databases.

  1. Download the VPN client from the IT Portal.
  2. Install the application using the default settings.
  3. Log in using your Single Sign-On (SSO) credentials.

Software Requests

If you need specialized software that is not pre-installed on your machine, follow this process:

  • Check the Self-Service App Catalog first.
  • If it requires a paid license, submit a ticket to the IT Procurement desk.
  • Note: Manager approval is required for subscriptions over $50/month.
